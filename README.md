# Customer Behaviour Analysis 📊

An end-to-end **Data Analytics project** focused on understanding customer purchasing behaviour and generating business insights using **Python, SQL, and Power BI**.

## 🔍 Project Overview

The project analyses customer demographics, purchasing patterns, product performance, discounts, subscriptions, shipping methods, ratings, and customer loyalty.

### 🛠️ Tools & Technologies

* **Python** – EDA, data cleaning & feature engineering
* **SQL** – Business analysis & customer segmentation
* **Power BI** – Interactive dashboard & visualization

### 📌 Key Analysis

* Revenue analysis by customer segment
* Product performance & ratings
* Discount behaviour
* Subscription analysis
* Shipping analysis
* Customer segmentation
* Top products by category

### 📁 Project Files

* `Customer_job_Business_Analysis.ipynb` – EDA & data preparation
* `Customer_behaviours.sql` – SQL business queries
* `Customer_Behaviour.pbix` – Power BI dashboard
* `Customer_Behaviour_Analysis_Report.docx` – Detailed project report
* `Customer_Behaviour_Stakeholder_Presentation_Enhanced.pptx` – Stakeholder presentation

## 🚀 Future Scope

The project can be extended with **time-series analysis, customer retention, RFM segmentation, Customer Lifetime Value (CLV), promotion ROI, and predictive analytics**.

**Goal:** Transform customer data into actionable insights for better business decision-making.
